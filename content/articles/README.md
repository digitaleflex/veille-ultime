# Articles Markdown

Les fichiers `.md` de ce dossier constituent la source éditoriale des articles publics. Chaque fichier publié doit comporter un frontmatter valide avec `slug`, `title`, `category`, `publishedAt`, `sourceName`, `sourceUrl`, `excerpt` et `takeaways`.

## Avant de publier

- Lire `content/METHODOLOGIE-EDITORIALE.md`.
- Vérifier les faits et les versions dans une source primaire précise.
- Utiliser l’URL directe de la publication ou de l’avis officiel quand elle existe.
- Séparer les faits attribués à la source de l’analyse de Veille Ultime.
- Donner des recommandations concrètes, limitées et vérifiables.
- Vérifier les liens, le titre, la description SEO, la date et l’absence de répétitions génériques.

`_template.md` est un modèle et les fichiers commençant par `_` ne sont pas publiés. Les contenus non vérifiés ne doivent pas être mis en ligne.
